### 📌 Como eu uso IA

A IA escreve mais rápido do que eu. O que ela não faz: decidir o que é seguro rodar em produção. Por isso todo projeto aqui segue a mesma regra: lógica separada do I/O, testes automatizados, segredos fora do código e escrita em sistema real só com confirmação humana.
